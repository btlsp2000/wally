PMAPPER MODULE

The Perimeter Hub (/pmapper) is a specialized standalone module designed to translate geographical coordinates (Latitude/Longitude) into planar Cartesian geometry for WallyCAD preview and export.

Canvas Translation Engine

The core rendering function applies a direct mathematical translation to plot spherical coordinates onto a 2D HTML5 canvas, shifting the origin to keep the US West Coast in frame:

let y = canvas.height - ((Lat - 31) * 40); let x = (Long + 125) * 40;

This isolates geographical polygons—such as the borders of Washington, Oregon, or California—and scales them for immediate visual verification before they are committed to an SDJ string.

Dynamic State Library

The left pane sidebar dynamically builds a clickable library based on an internal JSON object (Perimeters). Clicking any card instantly recalculates the bounds and renders the closed loop on the preview canvas.

QC COMMAND LINE

The /pmapper module features an integrated QuickClick (QC) command line interface anchored to the bottom of the viewport, enabling rapid data entry and execution without touching a mouse.

The ADD Syntax

Users can inject new geographical boundaries directly into the active session memory by typing into the QC CLI. The command follows a strict tokenized syntax:

ADD [NAME] [LAT1] [LON1] [LAT2] [LON2]...

Example: ADD NEVADA 42.0 -114.0 42.0 -120.0...

Pressing Enter will parse the string, push the new entity into the Perimeters library, rebuild the sidebar, and instantly render the new state.

Global QC Hotkeys

When the CLI input box is not focused, the module listens for global keystrokes to execute macro commands:

  • [ 4 ] : Instantly renders the Four Corners geometry.
  • [ C ] : Clears the canvas and deselects the active state.
  • [ G ] : Pipes the active state's raw coordinate data out for G-Coder formatting.
