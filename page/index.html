THE ARCHITECTURE

WallyCAD does not use "click-and-drag" drawing. It uses a precision spawn-and-modify sequence driven by a Command Line Interface (CLI). Every entity on the canvas is a pure, space-delimited Cartesian matrix formatted to four decimal places for absolute CNC/Laser precision.
