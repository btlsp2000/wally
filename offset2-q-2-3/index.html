FOOTPRINT OFFSET (/OFFSET2)

The Footprint Offset Generator is a specialized architectural module. It calculates the outward-expanded baseline required to render a physical [WALL] entity around an exact interior room loop without shrinking the square footage.

1. Winding Detection

The engine calculates the polygon area to determine if coordinates were drawn Clockwise or Counter-Clockwise. This guarantees the offset always pushes outward, eliminating manual positive/negative coordinate guesswork.

2. Baseline Halving

WallyCAD walls render equally on both sides of a coordinate baseline. The Footprint module automatically divides the input wall thickness by two to calculate the mathematically perfect center node matrix.

3. Path Closure Validation

If fed an open path, the data parser intercepts it and automatically appends the first coordinate to the end of the array, forcing a closed geometric loop suitable for architectural structures.

SDJ GENERATION

Unlike the general-purpose /offset tool, /offset2 operates purely on text matrices without a visual canvas, streamlining the structural drafting workflow.

[WALL] X1 Y1 X2 Y2 ... Xn Yn T:6

Hardcoded Entity Formatting

The module forces the output string to generate a [WALL] entity and automatically appends your exact wall thickness to the tail of the Space-Delimited JSON string (e.g., T:6).

Determinant Intersection Math

Instead of the core Vector Intersection Algorithm (VIA), the Footprint engine uses a lightweight determinant-based intersection formula specifically tailored to resolve angles and corner pinches in closed architectural loops.
