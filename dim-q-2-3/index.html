THE 3 DIM MODES

The engine now supports three dimension types to accurately document architectural layouts.

1. [DIM] - Aligned

The standard dimension. The measurement string runs perfectly parallel to the angle between Point 1 and Point 2. Used for diagonals and angled walls.

2. [DIMH] - Horizontal

Locks the measurement strictly to the X-Axis. Even if P1 and P2 are at different heights, the engine only calculates the horizontal distance between them.

3. [DIMV] - Vertical

Locks the measurement strictly to the Y-Axis. The engine isolates the vertical height difference. Text is automatically rotated 90 degrees to read bottom-to-top.

Smart Auto-Dimensioning

Select any object on the canvas before typing DIM, DIMH, or DIMV into the command line. The engine will bypass manual coordinate entry, read the object's extents, and instantly wrap a perfectly scaled dimension around it.

SDJ SYNTAX

The core schema for dimensioning relies on the T: parameter to define the offset distance.

[TYPE] X1 Y1 X2 Y2 T:OFFSET "TEXT"

The T: Offset Parameter

Unlike Walls or Lines where T: controls thickness, in a DIM entity, T: tells the engine how far to pull the dimension line away from the baseline nodes.

  • T:15 throws the line 15 units outward.
  • T:-20 throws the line 20 units in the opposite direction.

Command Line Examples

[DIMV] 0 0 0 108 T:-20

Measures the vertical height of a 108-unit wall, and places the dimension string 20 units to the LEFT of the wall.

[DIMH] 0 0 192 0 T:15 "16'-0"

Measures a 192-unit horizontal span, offsets it 15 units, and replaces the decimal output with custom text.
