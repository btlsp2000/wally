BLUE: Spine | WHITE: Curb Offset | GOLD: Cross-Tick Normal
ENGINE PARAMETERS
  • STRIP WIDTH: Defines the total face-to-face separation dimension between the parallel white CURB lines.
  • TICK OVERHANG: Sets the extension distance of the perpendicular gold CROSS-TICKS past the outer curb boundary.
  • SNAP GRID: Forces mouse clicks to round to nearest Cartesian intervals (e.g., 0.25, 0.5, 1.0).
DATA EXPORT
  • COPY .WALLY: Serializes the generated spine, curb, and tick geometry into a raw [X1,Y1,X2,Y2] tuple string matrix.
  • EXPORT .DXF: Compiles the canvas vectors into an ASCII AutoCAD .DXF file with distinct layers (MOW_SPINE, MOW_CURB, MOW_TICK) for immediate machine routing or surveying.
CANVAS NAVIGATION:
  • LEFT-CLICK: Drops a central spine node at the crosshair and instantly recalculates the miter bisectors.
  • AUTO-COPY: Every left-click automatically copies the exact Cartesian X,Y coordinate to your system clipboard.
  • RIGHT-CLICK: Undoes the last node.
  • CLEAR: Wipes the entire node array and resets the engine.
