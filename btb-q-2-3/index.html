THE BORDER/TITLE BLOCK FEATURE

The engine supports a dedicated command to automatically insert a standard architectural border and title block, simplifying layout prep[cite: 5].

1. Standard Size Bounding

  • Typing BORDER (or DB / DIMBORDER) generates a 110x85 landscape sheet border at the 0,0 origin, scaling it to accommodate typical small-scale architectural layouts[cite: 5].

2. Automated Title Block

  • The command places a 40x15 block in the bottom-right corner, pre-configured with PROJECT:, CLIENT:, DATE: 10/2026, and DWN: BEI fields, so you don't have to draw metadata lines manually[cite: 5].

3. Intelligent Layout Scaling

  • The system recalculates the bounds instantly upon drawing, zooming to the extents of the new border with centerView() so you can populate details without manual view panning[cite: 5].

SDJ SYNTAX

Deploying borders via SDJ requires specific command inputs or direct coordinates[cite: 5].

1. The CLI BORDER Command

  • Typing BORDER into the terminal instantly invokes createWallyBox(0,0,110,85,1) and maps out internal borders and text entries automatically[cite: 5].
[BORDER] X1 Y1 X2 Y2
  • A default 110x85 layout template, featuring the major outer border and divided text compartments[cite: 5].
[BORDER] 0 0 110 85 T:1
  • Draws a standard landscape sheet with a 1-unit line thickness[cite: 5].

2. Editing Labels

  • To override title block metadata, select the generated text entities on-screen and use the Properties sidebar to customize client names, project IDs, and draft dates[cite: 5].
