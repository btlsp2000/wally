QC COMMAND SYNTAX

Type your parameter string directly into the QC Input Box and press Enter:

T[SPAN]-[DEPTH]-[PANELS]
  • SPAN: Total horizontal baseline length (feet).
  • DEPTH: Vertical height from bottom chord to top chord (feet).
  • PANELS: Number of upper chord divisions.

Example: T12-2-8 (12ft span, 2ft deep, 8 panels)

DATA EXPORT
  • COORDINATE TABLE: Live matrix mapping every T-node and B-node explicitly in X,Y space.
  • EXPORT JSON: Serializes the generated chord nodes into a .json array for downstream engineering analysis or fabrication logic.
NODE ARCHITECTURE:
  • TOP CHORD (T): Nodes are spaced equally along the Y = DEPTH axis, incrementing exactly by SPAN / PANELS.
  • BOTTOM CHORD (B): Nodes are staggered to center exactly between the top nodes along the baseline Y = 0.000 axis, generating symmetrical structural webbing.
  • PTP LOGIC: Fully supports Plane to Plane mathematical integration.
