QSG Example Solution: Wrightwood Library South Wall Elevation (WLSWE)

This reference solution demonstrates how to construct the WLSWE using WallyCAD and associated parametric modules like wallycad.com/box. The elevation is built sequentially from the floor up, incorporating the border, title block, bookshelf, frame, 4 windows, and roof/ceiling gable components[cite: 4].

Component Specifications

  • Bookshelves: Width = 224, Height = 38, Insertion Point (X, Y) = 0, 0
  • Frame: Width = 224, Height = 173, Insertion Point (X, Y) = 0, 38
  • Window 1 (Lower Left): Width = 48, Height = 54, Insertion Point (X, Y) = 48, 59
  • Window 2 (Lower Right): Width = 132, Height = 54, Insertion Point (X, Y) = 48, 59
  • Window 3 (Upper Left): Width = 48, Height = 125, Insertion Point (X, Y) = 48, 59
  • Window 4 (Upper Right): Width = 132, Height = 125, Insertion Point (X, Y) = 48, 59

SDJ Coordinate Data Set

; WLSWE SDJ COORDINATE SET EXAMPLE
; Layer: 0 (Base Geometry)
RECTANGLE 0,0 224,38 ; Bookshelves (Floor Base)
RECTANGLE 0,38 224,211 ; Frame Elevation (H = 173 above 38)
RECTANGLE 48,59 96,113 ; Window 1 (Lower Left: W=48, H=54)
RECTANGLE 48,59 180,113 ; Window 2 (Lower Right: W=132, H=54)
RECTANGLE 48,59 96,184 ; Window 3 (Upper Left: W=48, H=125)
RECTANGLE 48,59 180,184 ; Window 4 (Upper Right: W=132, H=125)
GABLE_ROOF 0,211 224,249 ; Roof/Ceiling Gable 2x8's (4 Elements)
