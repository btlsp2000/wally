/TRUSS ANALYTICS

v1.0.10 | "The Year of the Trailer"

This module transitions WallyCAD from architectural elevation into dynamic structural engineering. The Truss Analytics standalone engine focuses on PTP (Point-To-Point) Logic, mathematically distributing load-bearing nodes across a specified span.

The QC Command Syntax

Replacing traditional graphical UI inputs, the engine utilizes a high-speed command line syntax to instantly generate geometry:

QC > T[SPAN]-[DEPTH]-[PANELS]

Example: T7-1-6 renders a truss with a 7-foot span, 1-foot depth, divided into 6 equal panels.

Geometric Distribution

  • Panel Width: Calculated automatically as Span / Panels.
  • Top Chord (T-Nodes): Placed incrementally at every panel width interval at the specified Depth (Y-axis).
  • Bottom Chord (B-Nodes): Offset horizontally by exactly half a panel width (i + 0.5) and pinned to Y: 0.000 to create the zigzag triangulation geometry.

DATA ARCHITECTURE

Node Extraction & Fabrication

The visual canvas serves only as a secondary confirmation tool; the primary output of the `/TRUSS` engine is the mathematical coordinate data required for physical fabrication and welding.

Coordinate Table Generation

As the PTP logic evaluates the QC command, it iterates through a generation loop, dynamically building a node array. Each joint in the truss is assigned an absolute Cartesian coordinate mapped to 3 decimal places (e.g., X: 3.500, Y: 1.000) representing true feet.

JSON Export Protocol

To bridge the gap between WallyCAD and external engineering tools, the module bypasses standard SDJ strings in favor of a structured data export.

  • Export Format: Generates a localized .json payload containing the full {id, x, y} mapping for every structural point.
  • Fabrication Use: This allows raw numerical layouts to be directly passed to CNC plasma tables, laser cutters, or shop floor ledgers for precision jigging.
