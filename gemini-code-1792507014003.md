## Overview
WallyCAD is a hybrid web-native and AutoLISP-based geometry engine designed for structural vector drafting, traverse operations, truss analytics, and parametric design. 

This commercial release contains the core AutoLISP engine files, standardized `.wally` JSON export schemas, and the complete 12-page digital reference manual.

## Package Contents
* `/engine/traverse.lsp` - Core polar translation engine (Open/Closed loop, side-shots).
* `/engine/trans-rot.lsp` - Transformation matrix generator for Element A rotations.
* `/engine/ptp.lsp` - Plane-to-Plane 3DFace similar triangle logic.
* `/schemas/` - Standardized `.wally` JSON coordinate exports.
* `WallyCAD_Manual_v1.0.15.pdf` - The 12-page Digital Reference Manual.
* `WallyCAD_Manual_v1.0.15.epub` - Fixed-Layout EPUB for digital readers.
* `EULA.txt` - End User License Agreement.

## Quick Start: Loading AutoLISP Solvers
To utilize the core `.lsp` files in your CAD environment (AutoCAD, BricsCAD, ZWCAD):
1. Extract the `.ZIP` archive to a secure local directory.
2. Open your CAD command line and type `APPLOAD`.
3. Navigate to the `/engine/` folder and select the desired `.lsp` file.
4. Once loaded, type the command defined in the routine (e.g., `CALC_NODE`, `ELEM_ROT`, `PTP`) to initialize the solver.
