CORE INPUT PROTOCOL

The v1.0.17 engine utilizes an aggressive space-delimited tokenizer designed for high-speed HTML5 canvas rendering. All vector data enters the engine through the "PASTE SDJ STRING" panel located in the Data Protocol sidebar.

The RegEx Gatekeeper

To protect the parser from failing on invisible formatting characters, the input panel routes all pasted data through a native JavaScript Regular Expression sanitization function.

.replace(/[\r\n\t]+/g, ' ') .replace(/\s{2,}/g, ' ') .trim()

This gatekeeper instantly strips carriage returns, line breaks, and tabs, flattening multi-line text into the pure 1-dimensional string required by the tokenizer. This allows users to paste raw columns directly from Excel or Google Sheets without breaking the canvas rendering loop.

Entity Tagging Requirement

The tokenizer sweeps left-to-right looking for valid floats. Naked coordinates will be dropped unless they are prefaced by a valid WallyCAD entity tag (e.g., [WALL], [LINE], [CIRCLE]) which tells the engine which active array to push the subsequent vector nodes into.

THE DATA FUNNEL

External data steps down through three distinct tiers of formatting complexity before hitting the canvas.

Tier 1: Heavyweight JSON

Standard JavaScript Object Arrays (e.g., [{"type":"line","x1":0...}]). Universal for web APIs, but bloated with syntax. Cannot be pasted directly into the core engine. Must be routed through the /jsontowally Data Converter or standalone Flattener module first.

Tier 2: Multi-Line SDJ

Human-readable Space-Delimited JSON blocks. Contains no JSON keys or brackets, but retains line breaks for notebook readability.

[LINE] 10 90 90 90 T:0 [LINE] 10 95 90 95 T:0

Supported Natively. The RegEx Gatekeeper intercepts these line breaks upon paste and sanitizes them into Tier 3 automatically.

Tier 3: The 1D Continuous String

The absolute bottom of the funnel and the engine's native language. A single uninterrupted text stream separated only by single spaces.

[LINE] 10 90 90 90 T:0 [LINE] 10 95 90 95 T:0

This format achieves zero-latency parsing, allowing the core to instantly render thousands of vectors without halting the browser thread.
