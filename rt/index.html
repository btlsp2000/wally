RIGHT TRIANGLE WITH /TRAPEZOID

The /trap module decomposes an orthogonal right triangle into a smaller similar right triangle and a complementary right trapezoid along either Cartesian axis.

1. Primary Datum & Nodes

  • Datum Node (0,0): The 90° right-angle vertex at the top-left corner.
  • Horizontal Base (B): Extends rightward along the X-axis to (B, 0).
  • Vertical Leg (H): Drops plumb along the negative Y-axis to (0, -H).
  • Hypotenuse: Vector connecting (0, -H) to (B, 0) with slope m = H/B.

2. Partition Derivations

Vertical Cut (0 < x < B):
Trapezoid Bases: b1 = H,   b2 = H · (1 - x/B)
Trapezoid Area: A_trap = x · (b1 + b2) / 2

Horizontal Cut (0 < y < H):
Trapezoid Bases: a1 = B,   a2 = B · (1 - y/H)
Trapezoid Area: A_trap = y · (a1 + a2) / 2

SDJ SYNTAX & CLI

The entity can be invoked directly from the CLI or parsed through the space-delimited SDJ tokenizer pipeline.

1. The CLI /trap Command

/trap X0 Y0 B H [cut_offset] [cut_axis]
  • X0 Y0 : Right-angle datum coordinate (default: 0 0)
  • B H : Horizontal base width and vertical leg height
  • cut_offset : Linear distance of partition cut from datum
  • cut_axis : Axis of cut line (V for vertical, H for horizontal)

2. SDJ Token Stream Output

[LINE] 0 0 120 0 0 -100 0 0 [LINE] 40 0 40 -66.6667

In this example (B=120, H=100 with vertical cut at x=40), the engine defines the closed right triangle and immediately adds the internal dividing partition as an editable line node.

3. Sub-Polygon Extraction

Using /explode separates the figure into two independent closed entities:

  • Trapezoid: [LINE] 0 0 40 0 40 -66.67 0 -100 0 0
  • Remainder Triangle: [LINE] 40 0 120 0 40 -66.67 40 0
