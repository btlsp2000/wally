CLI COMMAND SYNTAX

The engine plots relative survey offsets sequentially. Type commands directly into the CLI box and press Enter:

  • L {dist} : Turn Left (90°) relative to current heading and traverse dist units.
  • R {dist} : Turn Right (-90°) relative to current heading and traverse dist units.
  • T {dist},{ang} : Turn by a specific ang deflection and traverse dist units.
  • E : Zoom Extents (Fit active path to viewport).
  • W : Copy Wally Path to clipboard.
PATH EXPORT & SYNC
  • COPY WALLY PATH: Translates the relative sequence into absolute Cartesian points locked to 4 decimal places, formatted explicitly for the WallyCAD engine (**X,Y** pairs).
  • SYNC TO GIST: Pushes the raw traverse log to GitHub Gists for cloud retention.
CANVAS NAVIGATION:
  • SCROLL WHEEL: Zoom in/out of the active viewport.
  • CLICK & DRAG: Free-pan across the Cartesian grid.
  • ORIGIN ANCHOR: P0 automatically centers to the screen on initialization and is locked at 0,0.
SURVEYOR WORKFLOW:

Instead of manually calculating sine/cosine offsets, input boundary calls sequentially. The engine handles all trigonometry.

TRAVERSE ENGINE
The WallyCAD Traverse Engine converts sequential distances and deflection angles into precise Cartesian coordinates. It translates relative survey paths (Left/Right/Angle calls) into a continuous node array, automatically executing trigonometric math to export tuple scripts for immediate downstream DXF compilation or architectural framing.
