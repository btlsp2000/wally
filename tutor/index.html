This is your sandbox for the /s2 Master Viewport. Before we dive into complex multi-section arrays, let's get you comfortable with the core engine drafting mechanics.

1

The Master Viewport

The vast space to the right is the S2 Canvas. It is an infinite Cartesian plane. The origin 0,0 is dead center where the heavy axes cross.

2

The Command Line

Below this panel is the command input. WallyCAD is driven by direct text inputs. This keeps drafting fast and precise. You will type coordinates here.

3

Coordinate Entry

Let's draw. Type an X,Y coordinate pair and press ENTER. Try building a box by entering these one by one:

  • 50,50
  • 100,50
  • 100,100
  • 50,100
  • 50,50

Tip: Type 'clear' to reset.
