MATRIX TRANSFORMATION LOGIC
APPLYING LINEAR TRANSLATION & ROTATION MATRICES
MATRIX PARAMETERS
  • dX (Translation): Distance to shift the entire coordinate array along the horizontal X-axis.
  • dY (Translation): Distance to shift the entire coordinate array along the vertical Y-axis.
  • Deg(θ) (Rotation): Counter-clockwise angular rotation applied to every vertex around its datum point.
TRIGONOMETRIC SOLVER

The engine loops through the numeric string pairs and applies standard Cartesian transformations:

rx = X * cos(θ) - Y * sin(θ)
ry = X * sin(θ) + Y * cos(θ)

nx = rx + dX
ny = ry + dY
INPUT / OUTPUT WORKFLOW:
  • 1. PASTE TUPLES: Paste standard space-separated or newline-separated Cartesian pairs (X Y) into the top Input text area (e.g., from Stair arrays or WallyCAD exports).
  • 2. SET VALUES: Enter the desired translation and rotation limits.
  • 3. EXECUTE: Click the execution button. The script auto-trims whitespace, builds the transformation float arrays, and calculates output to 4 decimal places.
  • 4. COPY: Copy the newly rotated tuples from the Output buffer for DXF processing.

TRANS-ROT MATRIX
The WallyCAD Trans-Rot Matrix Engine acts as a standalone spatial translation tool. By parsing raw coordinate arrays—such as structural stair profiles, modular framing, or surveyed plot lines—and applying explicit translation vectors and trigonometric rotation angles, operators can instantly transform baseline orthogonal arrays into complex, skewed structural orientations without manual drafting.
