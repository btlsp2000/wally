The Cartesian Matrix & Origin Calibration

1. The Philosophy of Precision Cartesian Autonomy

Standard commercial CAD packages encourage a bad habit: "eyeballing" geometry with a mouse and hoping object snaps catch the error. In a structural steel fabrication shop or a field survey layout, visual approximation is a liability. If a baseplate anchor bolt is off by a fraction of an inch because a draftsman clicked a screen instead of defining a mathematical location, the steel will not fit the concrete in the field.

WallyCAD rejects manual click-and-drag drafting. Every piece of geometry in the engine is spawned through precision Cartesian autonomy—explicit numerical commands entered directly into the Command Line Interface (CLI) at wallycad.com/test. You do not draw shapes; you declare their exact coordinates in two-dimensional space, and the browser-native engine compiles the vector math instantaneously.

2. The X,Y Coordinate Plane & Datum 0,0

Before spawning a single line or wall, you must establish control. In land surveying and structural detailing, all measurements pull from a fixed Benchmark or Datum. In WallyCAD, that primary datum is the Absolute Origin (0,0).

  • The Horizontal Axis (X): Controls West-to-East displacement. Positive values move right (East) of the origin; negative values move left (West).
  • The Vertical Axis (Y): Controls South-to-North displacement. Positive values move up (North) from the origin; negative values move down (South).
  • Quadrant I Standard: Structural footprints and shop details are anchored in the primary positive quadrant (+X, +Y), keeping the lower-left datum corner locked at 0,0 so every subsequent dimension reads as a clean, positive offset from the baseline.

3. The 5x5 Calibration Matrix

To train your eye to read coordinate space before scaling up to full building footprints, WallyCAD uses a baseline 5x5 Reference Matrix. Think of this grid as a 5-unit by 5-unit pegboard running from 0,0 (bottom-left) to 4,4 (top-right) in zero-indexed space, or 0,0 to 5,5 in unit-span space. Every intersection on the matrix has a unique, unmistakable address:

  • Bottom-Left Corner (Origin): 0,0
  • Bottom-Right Corner: 5,0
  • Top-Left Corner: 0,5
  • Top-Right Corner: 5,5
  • Dead Center Node: 2.5,2.5 (or integer center 2,2 on a 0-to-4 index)

4. Terminal Syntax & The Parameter Compiler

The WallyCAD CLI parser is built for speed and zero ambiguity. It reads commands left-to-right using two simple punctuation rules:

  • Spaces separate distinct parameters (such as the Command Name, the Start Point, and the End Point).
  • Commas bind an X and Y value together into a single coordinate pair (X,Y) with no spaces around the comma.
  • Valid Syntax: LINE 0,0 120,0 (Clean command, space, X1,Y1 pair, space, X2,Y2 pair).
  • Invalid Syntax: LINE 0, 0 120, 0 (Spaces after the commas break the coordinate binding, causing the compiler to misread the Y value as the next parameter).

Zero-Thickness Vectors vs. Structural Mass (LINE vs. WALL)

1. Reference Geometry vs. Physical Material

In architectural drafting and steel detailing, a line on a screen can mean two entirely different things: an imaginary mathematical boundary (such as a property line, grid centerline, or survey traverse) or a physical assembly that occupies real-world space (such as a 4-inch or 6-inch framed wall).

If you draft a floor plan using only single zero-thickness lines, your interior clear spans will be wrong the moment lumber or steel arrives on site. WallyCAD solves this directly at the command line by separating pure mathematical vectors (LINE) from thickened structural mass (WALL):

  • LINE (Zero-Thickness Vector): Spawns a standard 0-thickness geometric path between two coordinate points. Use LINE for datum grids, centerlines, dimension references, and theoretical layout bounds.
  • WALL (Thickened Structural Polyline): Constructs a thickened polyline structure along a continuous coordinate traverse, using a specified thickness parameter to define the exact separation distance between parallel wall faces.

2. Automated Miter & Offset Logic

In traditional CAD, creating a multi-segment wall requires drawing a baseline, running an offset command for every segment, and manually trimming or filleting every corner intersection. When you execute the WALL command in WallyCAD, the parameter compiler automates the entire geometric construction:

  • Parallel Face Separation: The engine reads your thickness parameter and projects parallel inside and outside faces separated by that exact distance.
  • Continuous Traverse Miter: As your path turns a corner from one coordinate node to the next, the engine calculates the intersection vector and automatically miters the junction.
  • Corner Spike Control: At acute angles or specialized transitions, the parser calculates offset distances and replaces a single vertex point with bevel points, eliminating sharp miter spikes at corners.

3. Command Syntax & Parameter Order

Standard LINE Syntax: LINE X1,Y1 X2,Y2 Continuous WALL Syntax: WALL T X1,Y1 X2,Y2 X3,Y3 ...

Parametric Perimeter Spawning (BOX)

1. From Sequential Traverse to Macro Automation

In Module 1.2, framing a closed four-wall room with the WALL command required calculating and typing five sequential coordinate nodes to close the loop. While a continuous WALL traverse is essential for irregular or stepped footprints, most structural bays, room shells, and equipment pads are true rectangles.

To eliminate repetitive coordinate entry, WallyCAD provides the BOX macro (accessible in the main workspace and via the dedicated parameter compiler at wallycad.com/box). Instead of plotting four individual corners, you declare a single datum origin, overall exterior footprint dimensions, and wall thickness in one command line pass.

2. Command Anatomy & Five-Parameter Syntax

BOX X,Y Width Depth Thickness
  • X,Y (Origin Datum): The bottom-left exterior anchor point of the rectangular footprint (typically 0,0 for a primary building shell).
  • Width (X-Span): The total exterior horizontal dimension running East along the X-axis.
  • Depth (Y-Span): The total exterior vertical dimension running North along the Y-axis.
  • Thickness (T): The structural wall thickness stepped inward from the exterior perimeter.

3. Exterior Footprint vs. Interior Clear-Span Math

A critical discipline in structural detailing and shop fabrication is distinguishing between Out-to-Out (Exterior) dimensions and Inside Clear dimensions. When you execute BOX 0,0 120 96 4, the engine establishes the outside perimeter at 120 units wide by 96 units deep and projects the 4-unit wall thickness inward on all four sides. Because both opposing walls (West/East and South/North) consume 4 units of space each, you must subtract twice the wall thickness (2T) from each exterior dimension:

Exterior Width vs. Interior Clear Width: 120 - (4 * 2) = 112 units clear Exterior Depth vs. Interior Clear Depth: 96 - (4 * 2) = 88 units clear Interior Corners: SW (4,4) | SE (116,4) | NE (116,92) | NW (4,92)

Radial Vectors & Structural Pipe Profiles (CIRCLE)

1. Radial Geometry in a Cartesian World

In structural steel detailing and mechanical layout, circular geometry serves two primary roles: zero-thickness reference paths (such as door swings, rotational clearance zones, and bolt circles) and physical structural sections (such as Hollow Structural Section [HSS] round columns, schedule pipe bollards, and core-drilled utility sleeves). WallyCAD enforces strict Cartesian control over radial entities: every circle is anchored to an explicit X,Y Center Datum and compiled from exact numerical parameters for outer radius and wall thickness.

2. Command Anatomy: Radius vs. Tube Wall

The WallyCAD parameter compiler processes the CIRCLE command using a streamlined coordinate-and-dimension structure where the width parameter defines the radius and the depth parameter defines the tube wall:

CIRCLE X,Y Radius TubeWall Inside Radius: R_in = R - TubeWall | Outside Diameter: OD = 2R | Inside Diameter: ID = 2(R - TubeWall)
  • Zero-Thickness Reference (TubeWall = 0): Spawns a single-line radial vector for layout clearances, datum rings, or punched bolt holes.
  • Structural Pipe Profile (TubeWall > 0): Spawns a concentric hollow tube section (HSS round column or steel pipe).

3. Tangency & Corner-Offset Math

To tuck a pipe column of outer radius R tangent (flush) against two intersecting inside wall faces located at X = T_wall and Y = T_wall, you must offset the circle's center datum inward by the full radius R along both axes:

X_center = T_wall + R | Y_center = T_wall + R

Parametric Stair Tread Arrays (STAIR — 36-Inch Standard)

1. Automating Riser & Stringer Geometry

In traditional CAD, drafting a staircase requires drawing a baseline, executing ten to fifteen manual offset commands for individual risers, and trimming two parallel stringers. WallyCAD replaces repetitive offsetting with the parametric STAIR macro. By enforcing the updated 36-inch tread width standard (36 units), the engine generates uniform tread arrays designed for safe egress and straddle-frame structural configurations in a single CLI pass.

2. Command Anatomy & Total Run / Landing Math

STAIR X,Y Width Run Count (Standardized Width = 36 units) Total Horizontal Run = Run * Count Top Riser Y-Coordinate (anchored at Y=4): Y_top = 4 + (Run * Count) North Landing Clearance (inside 96-deep Box): L_top = 92 - Y_top

For a 5-tread flight with a 10-unit tread run (STAIR 4,4 36 10 5), the final riser lands at Y = 54, leaving 92 - 54 = 38 units of clear landing depth—exceeding the 36-unit minimum code requirement.

Precision Coordinate Dimensioning (DIM)

1. Mathematical Callouts vs. Visual Scaling

Traditional CAD dimensioning is prone to "snap drift"—where a drafter accidentally clicks a wall centerline instead of the true inside face. WallyCAD eliminates snap errors by driving the DIM command directly from explicit Cartesian coordinate nodes. The engine computes the true Euclidean distance, projects extension lines along the perpendicular normal vector, and drops the calculated distance into the center of the dimension line.

DIM X1,Y1 X2,Y2 Offset Euclidean Distance = sqrt((X2 - X1)^2 + (Y2 - Y1)^2)

LINE Lesson 1.2

Spawns a zero-thickness reference vector between two explicit Cartesian points.

Syntax: LINE X1,Y1 X2,Y2
DXF Layer: WALLY_LINE (ACI Color 3 - Green)
WALL Lesson 1.2

Spawns a thickened polyline structure of thickness T along a continuous coordinate traverse with automated corner mitering.

Syntax: WALL T X1,Y1 X2,Y2 X3,Y3 ...
DXF Layer: WALLY_WALL (ACI Color 4 - Cyan)
BOX Lesson 1.3

Spawns a closed, four-wall rectangular structural shell anchored at X,Y with inward wall thickness T and 45-degree corner miters.

Syntax: BOX X,Y Width Depth Thickness
Clear Span: W_clear = W - 2T | D_clear = D - 2T
CIRCLE Lesson 2.1

Spawns a radial vector or structural pipe column centered at X,Y. Width sets outer Radius; Depth sets inward TubeWall thickness.

Syntax: CIRCLE X,Y Radius TubeWall
Tangent Offset: Xc = Twall + R, Yc = Twall + R
STAIR Lesson 2.2 (36" Standard)

Spawns a parametric stair tread array anchored at bottom-left riser X,Y using the code-compliant 36-inch tread width.

Syntax: STAIR X,Y 36 Run Count
Total Run = Run * Count | Landing = (D - Twall) - Y_top
DIM & TEXT Lesson 2.3 & 2.4

Normal-vector Euclidean dimension callouts and 5x5 SquareFont vector annotations.

DIM X1,Y1 X2,Y2 Offset | TEXT [X,Y | S | R] [STRING]
DXF Layers: WALLY_DIM & WALLY_TEXT (ACI Color 2)
STAIR_RAKE & ARC Lesson 3.3 Solvers

Trigonometric rake pitch solver and Polar-to-Cartesian arc solver (R cos(phi), R sin(phi)).

STAIR_RAKE X,Y Rise Run Count | ARC CX,CY R Start End
DXF Layers: WALLY_RAKE & WALLY_ARC
