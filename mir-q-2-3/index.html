MIR | Vector Mirror Engine

System documentation for the S2-82 Vector Mirror module. This standalone engine mathematically reflects geometry coordinate blobs (V2) across a defined directional axis (V3) to rapidly generate symmetrical structural elements.

Axis Definition (V3)

The module establishes the plane of reflection by interpreting user input as a directional vector originating from (0,0). The UI allows discrete control over the X and Y components:

  • Horizontal Mirror: V3 = (1, 0). Reflects geometry over the X-axis plane.
  • Vertical Mirror: V3 = (0, 1). Reflects geometry over the Y-axis plane.
  • Arbitrary Angles: By inputting custom coordinates (e.g., 1, 1), the engine can mirror across diagonal planes like a 45-degree pitch.

Coordinate Parsing

The input processor ingests raw WallyCAD blobs via regex (split(/\s+/)) and iterates through the flat array in pairs, mapping every two sequential floats to a target Point (P).

Core Reflection Logic

The engine bypasses heavy matrix transformations by utilizing pure vector calculus to achieve the reflection.

Unit Vector Normalization

To accurately calculate the projection, V3 must be normalized into a Unit Vector (U) with a magnitude of 1. A default fail-safe resets to the X-axis if a zero-magnitude vector is entered.

const mag = Math.sqrt(vx * vx + vy * vy); if (mag === 0) { vx = 1; vy = 0; } // Default to X-axis const ux = vx / mag; const uy = vy / mag;

The Reflection Equation: P' = 2(P · U)U - P

For each parsed point (px, py), the engine calculates the dot product against the unit vector. The mirrored coordinate (mx, my) is dynamically generated and truncated to four decimal places for clean V6 output.

// Dot Product (P · U) const dot = px * ux + py * uy; // Reflection Vector calculation let mx = (2 * dot * ux - px).toFixed(4); let my = (2 * dot * uy - py).toFixed(4); result.push(`${mx} ${my}`);
