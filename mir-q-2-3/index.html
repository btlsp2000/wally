Responsive Split-Pane Architecture

The S2 environment utilizes a CSS Flexbox foundation to load distinct structural modules concurrently. The default state applies a flex: 1 ratio for a precise 50/50 split across the viewport.

  • Pane Left: Primary tool/drafting zone (Default: /qc QuickClick).
  • Pane Right: Secondary tool/archive zone (Default: / WAL Engine).

iPad Touch Optimization

Mobile browsers aggressively auto-zoom when interacting with small form inputs. The S2 module intercepts this behavior directly via CSS constraints:

/* iPad Touch Target Enforcement */ button, select, input { font-size: 16px; /* Minimum size stops iOS auto-zoom */ padding: 6px 10px; } #resizer { width: 20px; /* Expanded hit area for finger drag */ user-select: none; /* Prevents text highlighting */ }

Control Deck Logic

Dynamic routing and custom URL parameters are executed natively without requiring page refreshes, maintaining tool states in the inactive pane.

Execute Vector Protocol

The executeVector(side) function extracts input from the control deck and enforces standard HTTP protocol for external links to prevent iframe directory parsing errors.

let finalUrl = customUrl ? customUrl : presetUrl; // Enforce https:// for external domains if (customUrl && !customUrl.startsWith('http') && !customUrl.startsWith('/')) { finalUrl = 'https://' + customUrl; } iframe.src = finalUrl;

Dynamic Draggable Resizer

Width calculations are processed continuously against the active viewport bounding rect. Event listeners track both standard mouse movements and passive touch gestures (touchmove) to guarantee responsive sizing in the field.

function resize(e) { if (!isResizing) return; let clientX = e.type.includes('mouse') ? e.clientX : e.touches[0].clientX; let newLeftWidth = (clientX / viewport.getBoundingClientRect().width) * 100; // Hard limits to prevent pane collapse (10% / 90%) if (newLeftWidth > 10 && newLeftWidth < 90) { leftPane.style.width = `${newLeftWidth}%`; leftPane.style.flex = 'none'; rightPane.style.flex = '1'; } }
