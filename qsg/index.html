WallyCAD Quick Start Guide

Welcome to the WallyCAD Quick Start Guide,

WallyCAD simplifies CAD, is available online, and off and bypasses complicated, expensive industry software.

Take a look at this QSG. We want to get you into WallyCAD (wallycad.com) so we can generate accurate, professional digital drawing presentations.

Use this guide along side the WallyCAD User Manual.

1. The Control Panel (CP)

Check out the Control Panel (CP)—this is the master spreadsheet of all WallyCAD apps to-date.

2. Easy Starting Point: The "Box" App

    The Wrightwood Library South Wall Elevation. We use WallyCAD wallycad.com and apps associated to construct the WLSWE with a border and title block.

    Components: The WLSWE consists of the "Frame", the "Bookshelf", 4 Windows, and the Roof/Ceiling Gable Roof 2x8's. 4 elements.

    Construction Sequence: We construct one element at a time, start at the floor with the Bookshelf. Use wallycad.com/box for all but the Roof/Ceiling components, create the rectangles. See specifications.

    WLSWE Solution

3. WLSWE Specifications:

  1. Bookshelves: W = 224, H = 38, Insertion Point = x, y = 0, 0
  2. Frame: W = 224, H = 173 Insertion pOINT = X, Y = 0, 38
  3. Window 1(Lower Left): W = 48, H = 54, Insertion Point = x, y = 48, 59
  4. Window 2(Lower Right): W = 132, H = 54, Insertion Point = x, y = 48, 59
  5. Window 3(Upper Left): W = 48, H = 125, Insertion Point = x, y = 48, 59
  6. Window 4(Upper Right): W = 132, H = 125, Insertion Point = x, y = 48, 59
