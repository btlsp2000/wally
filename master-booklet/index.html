THE ELLIPSE ENGINE

The Ellipse Standalone Module is a parametric calculator designed to generate mathematically pure curved geometry using straight-line vector arrays.

1. Major and Minor Radii

WallyCAD requires two radii to plot an ellipse. The X-Radius (Major) dictates horizontal stretch, while the Y-Radius (Minor) dictates vertical stretch.

2. Segment Resolution

Because the core engine renders via coordinate arrays, curves must be faceted. Increase segment count for smoother arcs, or decrease it for polygons.

3. Axial Rotation

Enter a degree value to tilt the ellipse on its origin point before generation, eliminating the need to manually rotate complex matrices.

SDJ GENERATION

The module automatically translates the parametric math into a raw, copy-ready Space-Delimited JSON (SDJ) string.

[LINE] X1 Y1 X2 Y2 ... Xn Yn T:0

Workflow Integration

Upon clicking "GENERATE", the module plots the curve on the preview canvas and instantly copies the finalized string to your clipboard.

  • Navigate back to the WallyCAD v17 core engine.
  • Click the command bar input field.
  • Paste the string (Ctrl+V) and press Enter.

Entity Type Override

By default, the engine outputs the matrix as a [LINE] entity. You can manually change `[LINE]` to `[WALL]` and adjust the `T:` parameter before pasting to create a thick boundary.

THE SDJ CONVERTER

The JSON-to-SDJ module is the foundational data bridge for WallyCAD. It strips proprietary syntax bloat and reduces complex objects into pure text.

1. Flattening the Matrix

A standard `.wally` cache uses JS Object arrays. The converter flattens this syntax, replacing brackets and line breaks with space-delimited text.

2. The Gist Workflow

Because SDJ data is entirely plain-text, drawings can be backed up to GitHub Gists, shared over email, or pasted into chat terminals.

3. Cross-Compatibility

The parser accepts both standard WallyCAD Entity exports and raw Lat/Lng coordinate tuples, acting as a universal translator.

AUTO-SANITIZATION

As of v1.0.17, the converter actively cleans "dirty" inputs to ensure zero crash risk when pasting into the core CLI.

"Door Swing" -1.0 72.0 1.35 72.09

Comma Stripping

Older data blocks occasionally feature trailing commas attached to coordinate axes. The converter aggressively destroys these artifacts.

Intelligent Text Quoting

When line items contain alphabetical characters, the converter identifies them as architectural labels. It automatically wraps multi-word strings in double-quotes so the tokenizer does not trigger empty entity loops.
