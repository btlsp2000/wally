PARABOLA HYBRID V2

The wallycad.com/parabola V2 standalone merges the original y = x² mathematical macro framework with a responsive visualizer and optimized data extraction pipeline.

Core Parameters

The tool strictly adheres to the original CLI input syntax parameters:

  • Vertex (vx, vy): The origin anchor point mapping the geometric center.
  • Domain (Xmin, Xmax): The absolute limits dictating the horizontal span of the curve.
  • Grid Scale: The spatial multiplier expanding the base y = x² function.

Dual-Mode Geometry

Users can instantly toggle between two distinct subdivision algorithms:

  • Uniform Mode: Slices the domain into a user-defined number of equal, straight-line segments.
  • Fractional Notebook Mode: Uses a hardcoded geometric progression (0, ±1/4, ±1/2, ±1, ±3/2, ±2) designed to land precisely on standard imperial grid intersections.

PIPELINE & VISUALIZER

Pre-Flattened SDJ Output

The output generator eliminates external dependencies (like the Flattener or JSON converter). Calculated nodes are packaged directly into a 1-dimensional, space-delimited string of [LINE] entities.

[LINE] 0 0 4 1 [LINE] 4 1 8 4 [LINE] 8 4 16 16 T:0

This strict formatting guarantees zero-latency execution when pasted into the core v1.0.17 engine's CLI prompt.

Responsive Auto-Scaling

The internal HTML5 canvas calculates the coordinate deltas and dynamically scales the view. The parabola remains perfectly centered and visible on-screen regardless of the extreme aspect ratios caused by high Grid Scale multipliers.

Floating-Point Accuracy

To prevent cumulative drift, all vertices and endpoints are rounded precisely to 4 decimal places before SDJ array injection, safeguarding the structural integrity of intersecting CAD entities.
