PARSER PARAMETERS
  • RAW INPUT: Paste spatial data into the left bay. The engine accepts strictly structured, space-delimited text.
  • SYNTAX: [NAME] [X_COORD] [Y_COORD]
  • TOLERANCE: The parser utilizes Regex (`/\s+/`) to aggressively clean irregular spaces, tabs, and line breaks before extraction.
ENGINE OUTPUT FORMAT

Upon execution, the string arrays are mapped into pure float geometry explicitly built for the WallyCAD CLI:

POINT "NAME" X:0.0000 Y:0.0000

All Cartesian outputs are locked strictly to 4 decimal places via .toFixed(4) to ensure CAD drafting standards and downstream DXF stability.

WORKFLOW:
  • 1. INGEST: Paste unformatted spatial data, surveyor plots, or coordinate maps into the Raw Input bay.
  • 2. PROCESS: Click the "Parse & Plot" interface button. The engine validates arrays containing at least 3 parts per line.
  • 3. VERIFY: Check the status indicator at the bottom to confirm successful node compilation.
  • 4. EXPORT: Copy the reformatted syntax matrix directly into the active WallyCAD macro interpreter or Canvas CLI.
