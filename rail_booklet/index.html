ENGINE // MATH COREPG 05

STANDALONE VECTORS

Pure Cartesian array math ([x, y]) powers every offset, miter, and projection in v1.0.17:

  • Sum: [ax + bx, ay + by]
  • Dot Product: ax*bx + ay*by
  • 2D Cross (Det): ax*by - ay*bx (CCW vs CW turn test)
  • Normalize: v / Math.hypot(vx, vy)

Tested live in /vec with drag handles and grid snapping.
