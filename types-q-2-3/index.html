WALLY CAD COMPILER

LKA ENTERPRISE [V1.2]

The Wally CAD Compiler is a dedicated translation engine designed to bridge the gap between internal parametric text matrices and industry-standard external files. It acts as the final export stage for geometries bound for physical manufacturing or architectural plotting.

Input Syntax: Parametric Text Matrix

The compiler parses a specific human-readable, multi-line string format. Elements are declared with a strict Wally [Entity] prefix, and coordinates are separated by a forward slash /.

Wally Line 0.5,0.5 / 3,1.5 Wally Box 0,0 / 3.5,2 Wally Circle 1.75,1 / 0.25
  • Line: start_x,start_y / end_x,end_y
  • Box: origin_x,origin_y / width,height
  • Circle: center_x,center_y / radius

DUAL OUTPUT ENGINES

Engine 1: DXF Machine Path

The primary compiler translates the matrix into a universal Release 12 (R12) DXF plain-text schema, stripping away visual context in favor of pure CNC and CAD readability.

  • Primitive Decomposition: To ensure cross-compatibility with older machine protocols, parametric Wally Box entities are automatically mathematically decomposed into four discrete, endpoint-connected LINE vectors during compilation.

Engine 2: PDF Plotter

The secondary engine leverages the jsPDF library to generate flat, 8.5" x 11" architectural plots for human review. It applies a standard drafting pen weight (0.01) and establishes strict 0.5" document margins.

  • Cartesian Y-Axis Inversion: PDF coordinates originate from the top-left (0,0), while WallyCAD mathematics originate from the bottom-left. The engine intercepts all Y-coordinates and executes a real-time Cartesian inversion:
    y = pageHeight - marginY - coordinate.
