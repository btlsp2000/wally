TOURNEY UI & DISPATCH

The wallycad.com/tourney standalone web runtime provides automated single-elimination bracket resolution, real-time table dispatching, and room voice synthesis for cue sports tournaments.

Dispatch Architecture

  • Binary Knockout Tree: Pure deterministic 2N bracket pairing (Seeds 1v8, 4v5, 2v7, 3v6). Downstream nodes automatically accept winners with complete BYE auto-advancement.
  • Station Matrix: Configurable table bank (Tables 1–4 standard). Live status tags distinguish between OPEN stations and active IN PLAY racks.
  • On-Deck Buffer: Matches with confirmed opponents queue immediately. Hitting AUTO-DISPATCH assigns ready matches into open tables sequentially.
  • Voice Callout Engine: Uses browser speech synthesis to announce matches across the pool room (e.g., "Quarterfinals match on Table 1. Bill Tonnesen vs Alvin. Race to 2.").

Scoring & Standings Logic

Matches track individual game racks up to the designated target race length. Completed results feed directly into live leaderboard standings calculating match W-L, racks for (PF), racks against (PA), and net differential.

DATA PIPELINE & EXPORT

The controller executes 100% client-side with zero build steps, persisting the operational state directly to localStorage.

State Payload Structure

Tournament parameters, table allocations, and match nodes serialize into a clean JSON structure:

{"title":"Heritage Park 8-Ball","raceTo":2,"tables":[{"id":1,"matchId":3}],"matches":[...]}

Zero-Latency Dispatch

Assigning a table or confirming a match winner executes in O(1) time, advancing the player to the next round slot and freeing the station immediately without page reloads.

Top-Bar Direct Controls

The director console features top-level controls for quick operations: AUTO-DISPATCH, ANNOUNCE, RESET RACKS (clears tables and re-seeds active roster), PRINT (clean landscape scoresheet), and EXPORT (timestamped JSON backup).

Roster Persistence & Presets
