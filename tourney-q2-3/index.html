DOUBLE-ELIM DISPATCH

The wallycad.com/tourney director automates full 8-player double-elimination bracket routing, 4-table dispatching, and voice announcements for competitive 8-ball flights.

Dual-Bracket Routing Topology

  • UPPER BRACKET Winners: 3-round binary elimination (Matches 1–6, 11). Round 1 losers drop immediately into Losers Round 1 (M7, M8); Semifinal losers cross-drop into Losers Quarterfinals (M9, M10).
  • LOWER BRACKET Losers: 4-round survival flight (Matches 7–10, 12, 13). Second loss results in permanent elimination.
  • FINALS Grand Finals & Reset: Match 14 pits Winners Champ vs Losers Champ. If the Losers Champ wins, Match 15 (True Finals) activates dynamically to decide the title.

Station Dispatch Engine

Tables 1–4 are updated asynchronously. The autoDispatchTables() routine scans for ready matches (opponent slots populated in either bracket), moves them to open stations, starts match timers, and calls players to the felt.

Live Standings & Differentials

Every match score tallies points for (PF) and against (PA). Standings continuously display win-loss ratios and net rack differential, flagging active statuses: Undefeated, 1 Loss (Alive), or Eliminated.

DATA PIPELINE & RE-RACK

Built as a standalone, client-side controller saving direct to localStorage['heritage_pool_tourney_de'] without external database dependencies.

Deterministic Match Nodes

Matches carry explicit forward and drop vector pointers for instant $O(1)$ state propagation upon score confirmation:

{ id:1, winNext:5, winSlot:1, loseNext:7, loseSlot:1 } { id:11, winNext:14, winSlot:1, loseNext:13, loseSlot:2 }

True Finals Activation Vector

Match 15 remains inactive until Match 14 completes:

if (match.id === 14 && match.winner === match.p2) { m15.active = true; m15.status = 'scheduled'; }

Direct Header Controls

  • AUTO-DISPATCH: Assigns pending bracket matches to free tables.
  • ANNOUNCE: Triggers browser speech synthesizer match callouts.
  • RESET RACKS: Immediate one-click dialog to wipe scores, clear tables, and re-rack the active roster into Round 1.
  • EXPORT: Downloads full timestamped JSON tournament trees.

Roster Persistence & Heritage 8

Standardized seed layout: 1 vs 8, 4 vs 5, 2 vs 7, 3 vs 6. Features instant seed shuffling, custom additions, and preset restoration for the Heritage Park regular flight (Bill Tonnesen, Alvin, Art, Ken, Rick, Vince, Dave, Alan).
