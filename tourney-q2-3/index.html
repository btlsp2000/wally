TOURNEY UI & DISPATCH

The wallycad.com/tourney standalone web runtime provides automated single-elimination bracket resolution, real-time table dispatching, and room voice synthesis for cue sports tournaments.

Dispatch Architecture

  • Bracket Generation: Deterministic binary knockout tree ($2^N$ grid). Auto-seeds the field (1 vs 8, 4 vs 5, 2 vs 7, 3 vs 6) with automatic bye advancement.
  • Table Matrix (1–4): Real-time station occupancy monitoring. Tracks active matches, table availability, and match elapsed timers.
  • On-Deck Queue: Linear buffer queuing completed bracket pairings and feeding them into open stations via AUTO-DISPATCH.
  • Speech Synthesis: Native browser PA announcer calling matches to stations (e.g., "Quarterfinals on Table 1. Race to 2.").

Scoring & Standings Logic

The state engine continuously records rack differentials (PF/PA) and match records across all completed games, maintaining an active room leaderboard alongside the elimination bracket.

DATA PIPELINE & EXPORT

The tournament controller functions entirely client-side, persisting state to localStorage while integrating with the core WallyCAD command structure.

State Payload Structure

Tournament parameters, table allocations, and match progressions serialize into a flat JSON state array:

{"title":"Heritage Park 8-Ball","raceTo":2,"tables":[{"id":1,"matchId":3}],"matches":[...]}

Zero-Latency Dispatch

Station assignments and score updates resolve in O(1) time. When a match concludes, the station is instantly marked open and the winning player advances up the binary bracket tree without full-page re-renders.

WallyCAD Integration

Match results and rack differentials can be exported directly via the EXPORT controller or converted into vector layout tables for inclusion in broadsheet issues and Route 2 tournament dispatches.

Roster Persistence

Preloaded with Heritage Park pool hall regulars (Bill Tonnesen, Alvin, Art, Ken, Rick, Vince, Dave, Alan) with instant random seed shuffling and walk-in entry support.
